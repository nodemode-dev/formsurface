# FormSurface parity

Substance 3D Painter is a trademark of Adobe in the United States and/or other countries. It is named here only to describe what FormSurface's feature coverage was measured against; FormSurface is not affiliated with or endorsed by Adobe, and its features carry their own names.

Measured against Substance 3D Painter 12.1.5 on 50 documented capabilities, v0.56.3 scores 47.5 of 50 (95 percent): the painting core, OpenColorIO 2 color management with an ACEScg working space, a path tracer with glass, subsurface scattering, depth of field, a denoiser and renders to file, texture sets each with their own channel list (an optional fifth channel), an intelligent asset browser with thumbnails and shareable asset files, a Python API embedded in the editor with events and plugin buttons, mask effect stacks, UV tiles with per-tile resolution, layer instancing across texture sets for every layer kind and folders, all seven fill projections including warp and fill per UV tile, the path tool with paint, ribbon, filled and erase modes, true polygon fill on OBJ and PLY quads and n-gons, mesh export with n-gons, tessellation and displacement, headless batch runs, GPU ray-traced baking, mesh reload with reprojection, mesh import including USD, per-resource color space, viewport post effects, custom bake cages, engine and renderer export presets, brush engine, every layer blend mode, clone from the stack or a layer, 2D view painting, merge down and folder flatten, quick mask, text resources, output templates, export formats and padding, HDR environment lighting, fill layers, masks, folders, baking from the mesh and from a high-poly mesh (normal, ID, height, opacity, AO, bent normal) with match by name, generators with a mask builder, intelligent masks, filter layers with levels, posterize and pixelate, intelligent materials, texture sets per material, UDIM tiles with one shared stack are real; painting channels beyond the four (one extra role per set plus two named user channels), user channels (up to three per set against the reference's eight), channel bit depth (16-bit float throughout, no per-channel choice), resolution (4096 to work in; exports above 4096 recompute the stack but 8192 has not yet run on a real GPU) and memory paging (whole texture sets rather than streamed tiles) are partial. The full page is in the planning sidecar.
