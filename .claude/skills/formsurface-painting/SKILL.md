# Painting with FormSurface over MCP

The tools give an agent hands; this skill gives the order of work. FormSurface is a projection painter: strokes project onto the visible surface from the current camera and land in UV textures, on the active layer, with the current brush and paint material.

## Before anything

1. Call `formsurface_status`. If it fails with "No FormSurface editor is linked", ask the person to open http://localhost:5176 and press Agent link in the top bar; if the service is not running, ask them to run `./formsurface`. Do not retry blindly.
2. Read `texture_sets`, `active_texture_set`, `layers`, `active_layer`, `brush`, `paint_material`, `camera` and `viewport` from the status. Layer ids are what later calls take.
3. A mesh with several materials, or UVs outside 0 to 1 (UDIM tiles), has one texture set per material and tile, each with its own layers, base material and maps. Call `formsurface_select_texture_set` before working on a part; strokes, layers, fills and intelligent materials only reach the active set, so a stroke over another set paints nothing there. Layer ids belong to their set. When the same fill or filter should look identical on several sets (one paint across body and trim), build it once and `formsurface_instance_layer` it into the others; later edits to any copy reach all of them. For a material spread over UDIM tiles, turn on `formsurface_uv_tiles` first (before painting, because it resets the other tiles to the active tile's stack): its tiles then share one stack and strokes cross tile borders.

## The loop that works

1. Set up the surface: `formsurface_set_base_material` for the material under everything.
2. One idea per layer: `formsurface_add_layer` with a descriptive name, so the person can hide or tune it later.
3. Choose what paints: `formsurface_set_paint_material` sets values and which channels a stroke writes. Switch off channels you do not mean to change (for a color-only tint, turn off roughness and metallic).
4. For broad coverage add a fill layer with `formsurface_add_fill_layer` (a base material, or a pattern through tri-planar projection when UVs are messy), then tune it with `formsurface_set_fill`. To refine where a material shows without repainting, stack mask effects with `formsurface_layer_mask` effects (for example a generator multiplied over the painted mask, then levels to tighten it, then a small blur). To fit a logo or pattern onto a curved area, use projection warp and move warp_points; for a UDIM model with one texture per tile, turn on UV tiles and pass tile_images. To put a material only in some places, give that fill layer a black mask with `formsurface_layer_mask`, set the paint material's base color to white and paint the mask; black paint hides it again. When the places follow the shape or a part, use `formsurface_mask_source` instead: cavity, edges, thin or top after a bake (it updates with every bake), or id_color to take one part of the baked ID map, picked by pointing at it. `formsurface_fill_layer` floods the active paint layer instead.
5. For wear and grime that follow the shape, run `formsurface_bake_maps` once per mesh, then give fill layers a generator with `formsurface_set_generator`: cavity for dirt in crevices, edges for worn edges, thin for thin parts, top for dust or fading from above, dirt and metal_edge_wear for the same broken up with grunge, light for sun fading on the faces turned toward a direction, position for a gradient along one, noise for blotches, and mask_builder to mix cavity, curvature and noise by weight. Adjust level and softness, add noise (with noise_scale) to break up a clean edge, then screenshot. For overall color or roughness shifts, or to blur or sharpen what is below (soften a hard height stroke, crisp up a fill), add a filter layer with `formsurface_add_filter_layer` above the layers it should change and tune it later with `formsurface_set_filter`.
6. Fastest start: `formsurface_list_smart_materials`, bake, then `formsurface_apply_smart_material` (worn painted metal, rusty iron, dusty plastic, brushed gold, or anything the person saved). Retune one layer with `formsurface_apply_smart_mask` or `formsurface_set_generator`, and save a good result with `formsurface_save_smart_material`; a generator setup worth reusing on its own becomes an intelligent mask with `formsurface_save_smart_mask`, which then applies to fill layers or as a mask on any layer. When the person wants to judge materials under real lighting, `formsurface_set_environment` with an .hdr from the workspace environments folder (rotate it to move highlights; it only changes the viewport, not the exported maps). For an ACES or studio pipeline, `formsurface_color_management` with working_space acescg (set it before painting; switching later converts layers and clears undo) and a built-in OCIO config (or an .ocio file the person put in the workspace ocio folder) and its display and view, and `formsurface_set_color_space` with ocio: and a config color space for textures or HDRs authored in, say, ACEScg. For a final look with soft shadows and light bouncing between parts, `formsurface_path_trace` with on true and samples (64 is a fair preview, add denoise true for a clean image from few samples) before `formsurface_screenshot`, or `formsurface_path_render` for a PNG at a chosen size such as 1920 by 1080; turn it off again before painting at length, since strokes show the raster view and every change restarts the samples.
7. When the person has a high-poly sculpt, have them put it in the workspace meshes folder and run `formsurface_bake_high_poly` with its file name before painting; raise the cage distances if the result reports texels that missed. When parts sit close together and are named in pairs (bolt_low and bolt_high), pass match_by_name so one part's detail never bakes onto its neighbour. The bake also gives height, opacity, and (ao_rays above 0) ambient occlusion and a bent normal from the high-poly detail; ao_high, height_high and opacity can be packed into custom export maps. When the distance cage misses or overlaps parts, have the person save a cage (the low mesh with vertices pushed out) to the meshes folder and pass it as cage_file. For presentation screenshots, formsurface_set_post_effects adds bloom, depth of field, vignette and color correction to the viewport only; reset them before judging colors. Images the person puts in the workspace images folder import with formsurface_load_image; when a texture looks washed out or too dark, it was saved in the other color space, so switch it with formsurface_set_color_space rather than repainting. For repeatable jobs the person can also run Python against the same tools with ./formsurface script and the formsurface_api package, and both batch and script take --headless to run with no editor open; the same API also runs inside the editor's Python panel, where event and ui let a script react to strokes or exports and add plugin buttons. When the person brings an updated version of a model they already painted, load it with reproject true so the painting follows the surface instead of the old UVs; check the result with a screenshot, because texels farther than 5 percent of the radius from the old surface come out empty.
8. For marks, place the camera with `formsurface_set_camera`, call `formsurface_screenshot`, find where the surface sits in the image, then `formsurface_paint_stroke` with normalized viewport points (0,0 top left, 1,1 bottom right) along that region. The result reports `points_on_surface`; zero means the stroke missed, so re-aim instead of repeating.
For a whole part rather than a mark (a bolt, a panel, a UV island, one flat face), use `formsurface_polygon_fill` at a point on it instead of strokes: mesh fills the connected part, uv_chunk the UV island, polygon the flat face, triangle a single triangle. It uses the paint material at stroke opacity and is one undo step.
To keep paint off an area for a while (a label, a seam, everything except one panel), use `formsurface_quick_mask`: mode edit with action clear, paint or polygon-fill the allowed area, then mode on; every later stroke and fill only lands there, and the screenshot shows protected areas in red. Turn it off before the final screenshot. It is temporary and not undoable; for anything the person should keep, use a layer mask instead.
For a clean line or outline (a seam, a stripe, a ring around a part), use `formsurface_paint_path` with a few control points instead of a hand stroke: the curve is smooth and stays on the surface. mode ribbon gives an even band with no stamp overlap (with an image tip, a repeating trim pattern along the curve), and mode filled paints a decal shape or patch inside the outline; aim the camera at the area first, since both apply to the visible surface. A stroke passed to `formsurface_paint_stroke` joins consecutive points in a straight line through space, so give it dense points along the surface.
For an area the camera cannot reach (inside a cavity, under an overhang) or for marks that must follow the UV layout, `formsurface_view_2d` on, screenshot, then stroke on the layout; turn it off to check in 3D.
For lettering, `formsurface_text_resource` turns text into the brush tip (single stamps, spacing 1), a stencil (strokes reveal the letters; give the stroke dense points), or the active fill layer's image (white text becomes coverage in the fill's color; use planar projection facing the camera, scale 1). The cleanest decal is one stamp: tip from text_resource target alpha, alignment camera, spacing 1, symmetry off, the camera square to the surface, one paint_stroke point; the image keeps its proportions inside the brush square (up to 400 px). Before any lettering or asymmetric marking, read `uv_shared` for the texture set (list_texture_sets or status): it is the share of the set's UV area that several triangles map to. Paint there appears on every surface sharing those texels, so on a mirrored model (uv_shared near 1) text reads backwards on the other side and echoes onto other parts. With a high uv_shared, keep the design symmetric and readable both ways (stripes, chevrons, shapes, numbers that mirror cleanly), check every side with screenshots after each decal, and tell the person that readable text needs unique UVs.
To repeat a detail (a bolt, a scratch, a logo already painted), `formsurface_clone_source` at it, then stroke where the copy goes; to copy only one layer's paint (not the material under it), `formsurface_clone_layer` with that layer first, and 0 afterwards. Return to painting with `formsurface_set_brush` eraser false. Never call `formsurface_flatten_stack`, `formsurface_merge_down` or `formsurface_flatten_folder` unless the person asked: they are not undoable, and merging a layer whose blend mode is not normal bakes it as normal where the layer below is empty. To hand one layer to another tool, `formsurface_export_layer`.
9. Check with another screenshot from a second angle. Strokes paint only what the camera sees; turn the camera to reach the other side. Cover the whole model, not the faces the default camera shows: before finishing, screenshot the top, bottom (negative pitch), both sides, front and rear, and paint whatever is still the base material. In `formsurface_set_camera` a zoom above 1 moves the camera away and below 1 moves it closer.
   Surface detail (seams, grooves, rivets, scratches) lives in the height channel and becomes the exported normal map. It is fine detail: judge it only in close-ups (zoom about 0.3 to 0.5), never from the full-model view, where it is a few pixels wide and looks absent. Use clear values (height 0.8 to 1 against a 0.5 surface for grooves), paint panel seams as thin paths or strokes with paint_height on and color off, and check `formsurface_export_maps` gives a normal map that is not flat.
10. Undo is per stroke or fill (`formsurface_undo`), up to 24 steps, and belongs to the active texture set. The document lives in the open editor: on long jobs `formsurface_save_project` after each finished stage (it stores every layer and its pixels), and `formsurface_open_project` resumes after the editor or machine restarts.
11. Finish with `formsurface_export_maps`, which returns the folder of base color, roughness, metallic, height and normal PNGs for every texture set (bakes add their maps). When the person names a target engine, pass its template (gltf, unreal, unity_hdrp, unity_urp); for any other layout, pass custom_maps with packed sources, and if the person will reuse that layout, save it with `formsurface_save_export_template` and export by its name. Bake first so packed AO is not plain white. Pass bit_depth 16 when height or normal maps will drive displacement or close-up detail; for film or offline renderers use format exr (bit_depth 16 or 32, base color is then linear), for compositing tools tif or psd, and jpg only for previews. Keep padding infinite unless the person asks for transparent edges (png, tif, exr or psd only), a fill color, or diffusion. When the person needs the model too, `formsurface_export_mesh` writes it as OBJ beside the maps; it keeps quads and n-gons from OBJ or PLY sources unless ngons is false, and subdivide with displacement bakes the painted height into real geometry for renderers without displacement maps.

Group related layers with `formsurface_add_folder` (for example all the wear of one material) so the person can hide or fade them together; intelligent materials already arrive in a folder of their own name. While a folder is the active layer, new layers go inside it.

## Judgment

- Brush size is in screen pixels, so it shrinks on the model as the camera zooms out. Zoom in (`zoom` below 1) for detail.
- Height 0.5 is flat; paint height only on its own layer so it can be removed.
- Masks for a game shader (wear, dirt, wetness) belong in named user channels: add them with `user_channels` on the texture set, paint them with extra2 and extra3, and pack them into one file with a custom template (r user2, g user3).
- Mirror X paints the opposite side through the mesh center; use it for symmetric models only. Radial symmetry repeats a mark around an axis (bolts on a wheel, panels on a can).
- Alignment: tangent_wrap (default) hugs curved surfaces; tangent_planar gives crisp decal-like marks on flat areas; camera paints exactly the screen footprint, stretching on grazing faces; uv follows the texture layout and distorts where the UVs do.
- For organic wear use the spray tip with size and position jitter; for seams and trims use follow_path with a square tip.
- Tell the person what you changed by layer name. Never delete their layers unless asked.
